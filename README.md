# Spring Boot 4, Spring 7 & Hibernate for Beginners

Repository containing my exercises and practical implementations completed while following the **Spring Boot 4, Spring 7 & Hibernate for Beginners** course by **Chad Darby** on Udemy.

This repository follows my progression throughout the training, with the different course sections organized into dedicated directories. The commit history also reflects the progression of the work over the course of approximately one month.

## Course

The training provides a practical introduction to the Spring ecosystem and covers the main concepts and tools used to develop Java applications with Spring Boot, Hibernate and JPA.

The course covers topics including:

* Spring Boot 4
* Spring Framework 7
* Spring Core
* Inversion of Control (IoC) and Dependency Injection (DI)
* Hibernate & JPA
* REST APIs
* CRUD operations
* Spring Data JPA
* Spring Data REST
* OpenAPI & Swagger
* Spring REST API Security
* Spring MVC
* Thymeleaf
* Spring MVC CRUD applications
* Spring MVC Security
* Advanced JPA mappings
* Aspect-Oriented Programming (AOP)
